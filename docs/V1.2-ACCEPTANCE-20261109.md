## Design, browser and privacy

- Information pages use a light reading surface; immersive inspections remain dark and intentionally uncluttered. Mobile 360/390/768px overflow and full-page screenshot checks are in CI.
- Start action is primary; a previous report can be restored from a collapsed local-file control without an upload.
- Explicit no-JavaScript fallback explanations are present in English and Portuguese. Fullscreen / marker interactions require JavaScript.
- User's notes are escaped in printable HTML; JSON restore checks report kind, uncertified state, file size, coordinates, categories, pattern vocabulary and compatible test mode.
- Current browser suite checks same-origin request behavior and absence of third-party tracking scripts on tested routes. Hosting-provider request metadata remains outside the local-app processing claim.
- Legacy high-impression tool paths stay available and retain separate static explanation text.

## Still not accepted: keep separate from implemented code

1. Real iOS Safari, Android Chrome, multi-monitor hardware / display scaling and physical screen inspection.
2. NVDA, VoiceOver and other assistive technology manual acceptance.
3. Lighthouse / real-user Core Web Vitals under a public deployment; CI smoke is not a performance score.
4. Official-domain Cloudflare live HTTP behavior, redirects, GSC ownership, Google indexing and actual impressions.
5. External SERP top-10 and editorial index admission review for each of the 14 gated landing pages; specially unresolved `dying pixels laptop`, `dead line of pixels`, and broad `brightness check` intents.
6. A genuine support/privacy contact address before making a production contact promise.

The product is **code-implemented and browser-acceptance-tested for the listed scenarios**, not yet verified as a fully launched, indexed and hardware-certified service.

## 2026-11-09 second functional refinement — inspection accuracy and accessible fullscreen

- Per-mark **color-by-color observation matrix** on screen: visible, not visible, not checked, with EN/PT-BR labels. This displays existing manual observations; it does not infer panel defects.
- **Viewport, scaling and orientation drift warning:** compare current viewport width/height, DPR and orientation against the marker's recorded values. Large differences trigger a reminder to inspect the same physical spot again. JSON includes `viewportChangedSinceMark` and `exportedAt`; printable HTML includes the change warning.
- Recomputed layout warnings on browser resize, visual viewport resize and device rotation rather than waiting for an unrelated user action.
- Import validation now rejects a legacy JSON mark whose pattern belongs to another test mode. Original unsupported claims are never silently accepted as valid evidence.
- Full-screen **minimal inspection mode** no longer leaves a full-width header obscuring the top of the screen; a compact, always-visible exit toolbar can move among all four corners. It includes a way to restore the full controls and respects safe-area inset spacing.
- Keyboard focus restoration when switching control layouts, plus Escape to exit and a test that Tab stays inside the active inspection.
- EN/PT-BR helper labels, printable report button, navigation, accessibility skip link, and correct light/dark browser theme colors were improved.
- Privacy policy now explicitly says that an imported JSON report is validated locally in the browser and that the inspection session is in-page memory, not automatically cloud-synced.
- GitHub Actions CI uses concurrent-run cancellation and read-only content permissions to avoid repeatedly running stale commits.
